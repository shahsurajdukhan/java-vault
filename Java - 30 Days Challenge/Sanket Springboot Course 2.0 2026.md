## Day-1 Basic Programming with JAVA  - Understanding Java Programming Lang

           Java Identifier is basically the variable name 
		   like `int marks = 30;` so here marks is the java identifier.
		   a variable is a location in memory to hold data.
		   to indicate the storage area, each variable should be given a unique name -> java Identifiers.
		   
		   Java is a statically typed language - which means all the variables must be declared before they can be used.
		java is case sensitive. age,AGE,aGE are all different variables  
		variable names must start either a letter, or an underscore _, or a dollar $ sign.
	int age;
	int _age;
	int $age; all 3 aree valid apart from these no other naming conventions are allowed

variable names needs to make sense.
